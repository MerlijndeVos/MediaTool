# Toolbox v3.3.1

## What's new

- **Syntax highlighting for code and logs.** A mod's files, in the install review and in **Settings → Mods**, are now coloured by language (Python, TOML, JSON, Markdown, JavaScript, TypeScript, CSS, YAML, HTML and shell). The log panel and saved log files colour timestamps, level tags, file paths, web addresses, quoted text, numbers, `key=value` pairs and tracebacks, and warning and error lines keep their colour. **Settings → Appearance** has a switch for code and one for logs, and a choice of colour scheme: *From the theme*, *GitHub*, *One* or *High contrast*, each in light and dark. The highlighter only loads when you first open a file. Closes #14.
- **Themes can colour code.** Themes have eight new `syntax-*` colours, used by the *From the theme* scheme and checked for contrast like the other colours. *High contrast* and the **Solarized** example (now 1.1.0) set them. A theme that does not uses the default colours.

## Install

Download from [GitHub Releases](https://github.com/MerlijndeVos/Toolbox/releases/tag/v3.3.1):

| Platform | File |
|----------|------|
| Windows | `Toolbox-Setup-3.3.1-win64.exe` |
| macOS | `Toolbox-3.3.1-macos.dmg` |
| Linux | `Toolbox-3.3.1-linux-{arch}.AppImage` |

Installers are **unsigned**. Windows SmartScreen and macOS Gatekeeper may ask you to confirm once (“Run anyway” / “Open”).

**ffmpeg** is not bundled in the installer. On first launch the app downloads a one-time essentials build into your user data folder.

## Updating from v3.3.0

Use **Settings → Updates → Update to v3.3.1** in the desktop app, or download the new installer for your OS from the table above.
