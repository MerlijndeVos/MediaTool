Toolbox mod market

Extra tools for Toolbox, made by other people. Search below, then install from Settings → Mods → Browse in the app.

Listed is not reviewed. A mod is code that runs with the same access as Toolbox: it can read, change and delete your files. The project does not check these mods. Toolbox shows you the code and what the mod declares before it installs anything; read it first.
Want your mod here? Open a pull request that adds it to index.json.
